# Tarea de Computación Gráfica (CC3501)

Este proyecto contiene la solución a la tarea de Computación Gráfica.

## Estructura del Proyecto

- `tarea.py` - Archivo principal de la tarea
- `requirements.txt` - Dependencias necesarias
- `README.md` - Este archivo

## Instalación

1. Crear el entorno virtual:
```bash
conda env create -n grafica -f environment.yml
```

2. Activar el entorno:
```bash
conda activate grafica
```

3. Ejecutar la tarea:
```bash
python tarea.py
```

## Recursos

- Repositorio del curso: https://github.com/PLUMAS-research/cc3501-computer-graphics
- Ejemplos disponibles en el directorio `examples/`
