============================================================
GUÍA DE VERSIONES DEL PERSONAJE
============================================================

Para cambiar de versión:
1. Abre el archivo main.py
2. En las primeras líneas (alrededor de la línea 75) encontrarás:
   ACTIVE_VERSION = 1  # <-- CAMBIA ESTE NÚMERO (1-5)
3. Cambia el número a la versión que quieras probar
4. Guarda el archivo
5. Ejecuta el programa con: python -m 60910000-1

============================================================
VERSIÓN 1: ATLETA PROPORCIONADO ⚽ (Actual - Realista)
============================================================
Descripción:
- Proporciones realistas y atléticas
- Torso mediano, brazos delgados profesionales
- Piernas bien definidas
- Aspecto de jugador de fútbol

Colores:
- Camiseta: Azul (RGB: 0.2, 0.3, 0.8)
- Piel: Beige claro (RGB: 0.9, 0.7, 0.6)
- Pantalones: Negro (RGB: 0.1, 0.1, 0.1)
- Zapatos: Café (RGB: 0.3, 0.2, 0.1)

Características:
✓ Proporciones armoniosas
✓ Colores clásicos deportivos
✓ Ideal para poses atléticas
✓ Versión equilibrada y profesional
